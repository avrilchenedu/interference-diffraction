# 干涉與繞射｜互動式線上教材

依資料夾內 10 份文件（01–08、10）製作的四章互動教材，附學習紀錄後端與教師後台。

## 兩種使用方式

### ① 公開網站（GitHub Pages，免安裝）
直接開啟網址即可使用全部功能。此模式沒有伺服器：
- 學生的作答、提問、學習地圖與操作紀錄只存在**學生自己的瀏覽器**；請學生在「我的紀錄」下載 JSON 交給老師。
- 教師後台（頁尾「教師後台」）可一次匯入多位學生的 JSON 檔彙整查看、匯出全班 CSV／JSON。
- 小波使用內建規則式追問。

### ② 教室伺服器（即時收集全班紀錄）
只需要 Python 3（不需安裝任何套件）：

```bash
python3 server.py
```

- 學生端：http://127.0.0.1:8000/
- 教師後台：http://127.0.0.1:8000/teacher（密碼在啟動時印出；可用 `TEACHER_PIN=1234 python3 server.py` 指定）
- 讓教室其他電腦連線：`HOST=0.0.0.0 python3 server.py`，學生用「老師電腦 IP:8000」開啟。
- 紀錄存於 `data/learning.db`（已列入 .gitignore，不會上傳）。

網頁會自動偵測：有伺服器就用伺服器模式，沒有就用瀏覽器端模式。

## 檔案結構

| 路徑 | 說明 |
|---|---|
| `static/` | 網站本體（GitHub Pages 發布此資料夾） |
| `static/content.json` | 四章教材、概念、測驗、學習地圖規則、照片出處 |
| `static/teacher.json` | 教師後台：教案、學習單判讀、題目卡、細目表、素材清單、腳本、整合規劃、學習困難 |
| `static/socratic.json` | 小波追問規則（L1–L3 提示、題目檢核） |
| `static/localapi.js` | 瀏覽器端後端（無伺服器時使用） |
| `static/assets/` | 15 張 Wikimedia Commons 照片、設計文件附圖 |
| `server.py` | 選用的教室伺服器（Python 標準函式庫） |
| `.github/workflows/pages.yml` | 推送到 main 後自動發布 GitHub Pages |

## 主頁（登入後）

| 分頁 | 功能 |
|---|---|
| 📚 章節統整 | 四章的核心問題、核心知識、概念詞（點開看說明）、進度、測驗分數、熟悉度、相關提問；可直接進入章節、複習學習單、單字卡 |
| 🗺 我的學習地圖 | ①寫下「干涉」「繞射」字面直覺與生活例子（小波追問）→ ②依你的文字生成想像畫面（程式產生的示意圖，可重新生成），問你「像不像」→ ③把能遷移回教材的想法放進概念圖，教材沒討論的（如聲音、彩虹）先放旁邊、可能的迷思會標示 → ④學完各章後解鎖節點，保留／修正／刪除原想法並加入新連結，產生新舊兩張概念圖對照 |
| ❓ 我的提問區 | 隨時記錄問題（自動建議可能的章節）；章首提醒相關提問，章末「回頭回答你的提問」；狀態：還不確定／部分理解／我能回答了。章節頁右上角也能開啟 |
| 📊 評量與複習 | 已學習 %、各章測驗首次與最新分數、概念熟悉度、提問與問小波次數；各章學習單與單字卡入口 |

- **登入**：學生代碼或「匿名登入」（隨機代號，可用同代號在別台電腦續學）。
- **全站進度條**：右上角「已學習 %」，依四章所有步驟計算。
- **每章結尾「知識點統整」**：小測驗（首次作答列入評量；答錯給提示可訂正，訂正後仍錯才顯示答案）→ 概念熟悉度分析（依測驗、選擇題嘗試次數、活動、小波提示、單字卡自評推估，可展開依據）→ 專屬複習學習單（不熟概念、成立條件、答錯題重練、自己的提問；可列印／存 PDF／下載 HTML）→ 單字互動卡（不熟的排前面，可翻面，「再看一次」會排回後面）。
- **行為紀錄**：登入、每次點擊、輸入（欄位與字數）、頁面停留秒數、離開／回到分頁、所有作答與修訂、學習地圖、提問、測驗、單字卡、小波對話。教師後台與匯出檔都看得到。

## 小波（互動小人物）的追問規則

依 08「A01」與 10 的 L1–L3 提示：每次一個主問題、最多三句、不代答；預測時不揭答案、觀察時不解釋。
同一錯誤給過 L1、L2 仍卡住 → 給 L3 並標記「轉教師」（後台可見）；再卡住即請學生舉手找老師。
規則在 `socratic.json`，可直接修改。

**選用 Claude**：`pip install anthropic` 並設定 `ANTHROPIC_API_KEY` 後啟動，小波會改由 Claude（claude-opus-5-5）依同一規則與教材內容追問；斷網、逾時或失敗時自動改回規則式。

## 學習紀錄

- 存在 `data/learning.db`（SQLite）：作答（初稿／修訂分開保存與完整歷程）、操作紀錄、小波對話與提示層次、轉教師標記、時間、教材版本。
- 學生：「我的紀錄」頁下載 JSON／CSV；共用電腦用完可清除本機暫存（伺服器紀錄保留）。
- 離線時作答先存在瀏覽器，連線後自動同步；重新整理可續作。
- 保管人、保存期限與刪除方式請由授課教師確認（08）。
